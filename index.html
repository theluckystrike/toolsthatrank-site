The SEO pipeline that
refuses to guess

An autonomous pipeline that researches a niche, builds a genuinely useful web tool, and ships it only when every number in it has been verified against a primary source. If it cannot prove a value, it publishes nothing.

Install Read the source
$ npx groundtruth --site example-cooking-converter --dry-run

The rule the whole thing runs on. The model never states a fact or a number. It finds sources, drafts prose, and tries to refute its own claims. Code fetches every value, recomputes every number, and re-fetches every citation to confirm it still says what was claimed. When data cannot be fetched, the pipeline holds the value and ships nothing rather than guess. That refusal is the product.

How a page gets made

Research runs first on purpose. Generate first and you are checking hallucinations afterwards. Research first and generation has nothing left to invent.

  1. Research before writing

    Agents search, read primary sources, and extract claims. Nothing is drafted yet. A claim with no source is dropped at the door.

  2. Validate every value

    Each number is fetched from its primary source, cross-checked against the median of its citations, range-checked and freshness-checked, or it is held back.

  3. Generate against the bundle

    Prose is written only from validated data. Every figure stays a token that the build step fills from code. The model never types a number.

  4. Refute it

    A separate agent attacks each claim. Two refutations out of three kills it. Then every cited URL is re-fetched and must still contain the claim.

  5. Earn the ranking

    Originality layers read what already ranks and score what this page adds beyond it. A page that only restates the competition is blocked, not shipped.

  6. Stop at the human gate

    A clean run halts and waits for you. The pipeline never publishes on its own.

What it is honest about

The engine guarantees a floor. It does not manufacture demand.

it does

Refuse to fabricate

No invented numbers, no uncited claims, no stale data presented as fresh. That floor holds under adversarial audit.

it does

Build real utility

Working calculators and converters, not articles about calculators. Utility is what earns the ranking.

it does not

Manufacture authority

Links, brand and time still decide competitive niches. Correctness is necessary and not sufficient.

it does not

Publish for you

Every clean run stops at a human gate. Deployment is opt in and degrades to a preview on any stack.
